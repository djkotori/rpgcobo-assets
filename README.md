# RPG-Cobo Assets

![Logo Image](header.jpg)

[⇒ Japanese](README.ja.md)

This is a repository that manages **default materials/templates** for RPG-Cobo.  
Voxels for maps, characters, UI, sounds, sample projects, etc.  
Contains the basic materials needed to start creating games with RPG-Cobo.

**You do not need to clone this repository to use RPG-Cobo. **  
When you install RPG-Cobo from the link below, the materials in this repository will be available by default.

```
https://rpg-cobo.com/download
```

---

## 📦 What's in this repository?

- **Voxel materials** (terrain/buildings/objects)
- **Character materials** (walking animation, etc.)
- **UI material** (window icon)
- **Sound material** (SE/BGM)
- **Template project**
- **Sample map/sample data**

---

## 🎮 How to use

This repository does not stand alone.[RPG-Cobo Portal](https://github.com/djkotori/rpgcobo-portal)It is designed to be loaded from the app and copied to the project.

However, you can copy this repository to create your own asset libraries and templates.  
We plan to write about how to do it soon at the [Document](https://rpg-cobo.com/guides/start).

## 📦 Repository configuration

RPG-Cobo consists of multiple repositories.

- **rpgcobo-tool**  
  Tool body (editor/game runtime)

- **rpgcobo-portal**  
  Project management app (app installed on your PC)

- **rpgcobo-web**  
  Official website and documentation

- **rpgcobo-assets**  
  Default materials/templates
